## Personas

### Persona #1 

```markdown

Name: Emily

Background: 
A student pursuing programming as a course they have been blind since birth 
with hearing and speaking abilities. 
A family member introduced her to programming and it transformed into personal interest, after hearing about its accessible support 
with assistive tools i.e. screen reading software and braille display devices. 

Goals: 
Want to develop a project that helps learning tutorial videos easier. Especially be able
to capture and read the transcript.


Needs: 
As Emily
I want to be able to use coding tutorial video to extract a segment of code 
example or sample from the video (capture a frame).

So that I can have a sample of the code in text format to work on. 

```

### Persona #2

```markdown
Name: Lucy

Background:
A motivated learner who enjoys problem-solving and has passion for technology. She 
became visually impaired losing all vision by age of 13. She has learned how to code with 
the help of assistive technologies such as screen readers, braille displays etc. 

Goals:
Her goal is to become a proficient programmer and software developer, creating accessible 
technology solutions. Aiming to master coding languages and help other visually impaired 
students. 

Needs: 
As Lucy I want to be able to capture the frame of a video and read the transcript of the tutorial of any video from my library.
So that I can save the code or paste it somewhere for learning. 

```
