## Personas 

```markdown

Name: Emily

Background: 
A student pursuing programming as a course they have been blind since birth 
with hearing and speaking abilities. 
A family member introduced her to programming and it transformed into personal interest, after hearing about its accessible support 
with assistive tools i.e. screen reading software and braille display devices. 

Goals: 
Want to develop a project that helps learning tutorial videos easier. Especially be able
to capture and read the transcript.


Needs: 
As Emily
I want to be able to use coding tutorial video to extract a segment of code 
example or sample from the video (capture a frame).

So that I can have a sample of the code in text format to work on. 

```
